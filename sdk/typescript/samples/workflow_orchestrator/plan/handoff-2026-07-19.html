Lessons learned

  • The product center is an agent-authored bounded TypeScript runtime, not improved V1/V2 subagent chat plumbing.
  • Reasoning effort, validation mode, and orchestration granularity are independent decisions.
  • TODOs describe visible progress; workflows own recoverability; sessions own continuity; stages own policy.
  • Preserve continuity with a lease. Split only for observed degradation, capability change, independence, or real parallelism.
  • Routing is host-owned. Workflows request capability lanes; cost is a tie-breaker after capability and lane affinity.
  • Mission proof precedes journey review; journey review precedes code quality; merge gates remain optional until landing.
  • Model contracts are claims. Host observations become authority only under a stage-specific evidence policy.
  • Durable events still need referential integrity before their payloads may authorize transitions.
  • Every intermediate phase must be enforceable. A promised guard in the next phase leaves a real bypass now.
  • Context lineage records what was supplied, not what a model privately remembered or considered.

What went wrong

  • The initial architecture overemphasized an external harness and companion review; both were corrected, and codex-review is out of scope.
  • Phase 2A.2a consumed thirteen sessions because scope recovery and late independent findings exhausted the original repair budget.
  • The first accepted-looking writer allowed terminal event ordering defects, partial authorization from malformed responses, and basename payload substitution.
  • The final model review then found fabricated payload references could still become evidence. A local repair moved validation before event append.
  • Run 07's ledger remains rejected even though the repaired tree is now independently verified; the accepted tree ref is the authoritative continuation boundary.
  • The bootstrap runner needs a first-class operator-interruption result so a stopped session does not remain marked running.
  • Status polling became too frequent. Future continuations should check terminal boundaries, not narrate unchanged activity.
  • Full repository formatting is unreliable in this long Windows worktree; package-scoped formatting is the proven fallback.
