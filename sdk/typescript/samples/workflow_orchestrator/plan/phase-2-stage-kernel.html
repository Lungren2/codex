Phase 2 · Stage kernel and durable envelope

Make runStage() the only privileged path. Reserve bounds before invocation and persist one terminal result for success, invalid output, timeout, cancellation, crash, or worker failure.

Envelope

StageResult {
  run_id, stage_id, invocation_id, parent_invocation_id, attempt,
  reserved_at, started_at, finished_at, status, output_claim,
  effective_settings, context_manifest, usage, tool_evidence,
  policy_violations, error
}

Implementation

  1. Persist the attempt reservation and immutable run deadline before starting inference.
  2. Count failed, timed-out, cancelled, invalid-contract, and crashed attempts.
  3. Snapshot model, effort, tier, permissions, environment, cwd, and parentage at start.
  4. Enforce source bytes, deadline, worker count, nested calls, concurrency, stored bytes, and returned bytes.
  5. Persist the terminal result through rollout trace; do not create a parallel evidence database.
  6. On restart, recover the original deadline and close abandoned reservations as terminal failures.

Proof

Table-driven integration tests cover every terminal state and bound. A kill-and-resume test proves the deadline and attempt count cannot reset. Trace replay reconstructs the invocation tree without consulting model prose.

Stop: terminal-result durability only; suspended isolate replay, automatic retry, and distributed execution remain deferred.
