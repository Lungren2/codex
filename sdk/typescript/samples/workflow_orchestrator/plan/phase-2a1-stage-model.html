Phase 2A.1 · Stage model and replay

Add the smallest authoritative data layer: bounded stage reservation and terminal events plus pure reducer invariants. This PR performs no new file I/O.

Contract

StageResult {
  run_id, stage_id, invocation_id, parent_invocation_id,
  code_cell_id, attempt, reserved_at, started_at, finished_at,
  deadline_at, status, effective_settings, evidence_refs, error
}

Implementation

  1. Add model/stage.rs; bound every free-form identifier and error field at construction or deserialization.
  2. Add reservation and terminal variants to raw_event.rs.
  3. Add reducer/stage.rs enforcing one reservation, one terminal result, immutable identity/deadline/parent fields, monotonic attempts, and known evidence references.
  4. Add a narrow guard in writer.rs: generic append APIs reject stage variants until Phase 2A.2 provides the only typed producer.
  5. Keep stage tests in reducer/stage_tests.rs; compare complete replayed envelopes.
  6. Preserve forward-reader compatibility: the new reader replays old bundles with empty stage state. Do not claim that old binaries can read new stage-bearing bundles.

Exact surfaces

  • codex-rs/rollout-trace/src/model/stage.rs — new bounded model.
  • codex-rs/rollout-trace/src/model/mod.rs and model/runtime.rs — stage map and code-cell edge only.
  • codex-rs/rollout-trace/src/raw_event.rs — raw event union.
  • codex-rs/rollout-trace/src/reducer/stage.rs — pure replay.
  • codex-rs/rollout-trace/src/reducer/mod.rs and reducer/code_cell.rs — dispatch and code-cell linkage only.
  • codex-rs/rollout-trace/src/reducer/stage_tests.rs — invariant proof.
  • codex-rs/rollout-trace/src/writer.rs — generic-append rejection guard only.
  • codex-rs/rollout-trace/src/lib.rs — minimal model exports.

Replay accepts a valid reservation/terminal pair and rejects duplicate identity, missing prerequisites, changed deadline or parentage/settings/evidence, non-monotonic attempts, unbounded fields, and a second terminal result. Oversized error text is deterministically truncated so terminalization cannot be stranded. Generic writer append rejects both stage variants. Target: under 500 complex production lines and under 800 total changed lines.

Stop: no writable stage producer beyond the rejection guard, sync, default trace, recovery, core, or code mode.
