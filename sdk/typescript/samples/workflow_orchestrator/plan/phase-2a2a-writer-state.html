Phase 2A.2a · Durable prerequisite state

Build a pure index over already-synced trace events. It decides whether a proposed stage request has a real code-cell source, valid thread/turn/inference ownership, durable evidence, and an available attempt number. It cannot emit a stage event.

Implementation

  1. Keep request/outcome value types in stage.rs; do not expose StageTraceContext::reserve yet.
  2. Add writer/state.rs that observes an event only after the writer reports it synced. Model the same thread, turn, inference, code-cell, source, and evidence ownership as the reducer.
  3. Keep code cells pending until a validated inference terminal event durably materializes the matching model-visible custom-tool call.
  4. Preflight reservation without consuming an attempt. Failed source, ownership, evidence, or parent checks leave state unchanged; a later valid retry may reuse the attempt.
  5. Keep the generic writer guard from Phase 2A.1 unchanged.

Exact surfaces

  • codex-rs/rollout-trace/src/stage.rs — request/outcome values only.
  • codex-rs/rollout-trace/src/writer/state.rs — private synced-fact index.
  • codex-rs/rollout-trace/src/writer.rs — post-sync observation hook and rejection guard.
  • codex-rs/rollout-trace/src/writer_state_tests.rs — pure transition proof.

A table covers valid materialization and rejects unknown/foreign thread, turn, inference, code-cell, parent, source, and evidence. The exact order CodeCellStarted → preflight fail → InferenceCompleted → preflight succeeds retains attempt 1. Malformed inference ownership never unlocks a source. Target: under 500 complex production lines and under 800 total changed lines.

Stop: no stage append, sync policy change, fault injection, code-cell public bridge, provisioning, or recovery.
