Phase 2A.2b · Required synced stage writer

Expose the only writable stage path. It is bound to the originating runtime code cell, consults 2A.2a's prerequisite state, syncs required evidence and events, and becomes permanently failed after any ambiguous event-log I/O error.

API

CodeCellTraceContext::stage_context() -> StageTraceContext
StageTraceContext::reserve(request) -> Result<StageReservation>
StageReservation::terminalize(outcome) -> Result<StageResult>

Implementation

  1. Bind stage context to the runtime cell ID already owned by CodeCellTraceContext; callers cannot substitute a model-visible call ID.
  2. Under one writer mutex, preflight through 2A.2a, sync payload data, append the event, sync the log, then commit writer state.
  3. After any write/flush/sync error that may have transferred bytes, poison stage writes until explicit reopen/reconciliation in Phase 2A.3.
  4. Terminalize exactly once. A duplicate returns the first durable result and never appends conflicting bytes.
  5. Use a private event-log seam for deterministic reserve and terminal fault injection.

Exact surfaces

  • codex-rs/rollout-trace/src/stage.rs — typed public handle.
  • codex-rs/rollout-trace/src/code_cell.rs — identity-bound bridge.
  • codex-rs/rollout-trace/src/writer/stage.rs — private transactions.
  • codex-rs/rollout-trace/src/writer/event_log.rs — sync and failure seam.
  • codex-rs/rollout-trace/src/writer.rs — thin lock/I/O facade.
  • codex-rs/rollout-trace/src/writer_stage_tests.rs — durable and fail-closed proof.

Drop/reopen after every successful reserve and terminal replays the complete envelope. Missing prerequisites consume no attempt. Injected post-write reserve and terminal failures make all further stage writes fail closed without adding duplicates. Generic append stays rejected. Target: under 500 complex production lines and under 800 total changed lines.

Stop: no lifecycle synthesis, log recovery, default trace provisioning, workflow cleanup, or core integration.
