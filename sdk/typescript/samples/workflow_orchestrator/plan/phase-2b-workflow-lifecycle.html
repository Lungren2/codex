Phase 2B · Workflow lifecycle and durable parentage

Connect workflow workers to the accepted trace substrate. Every live terminal path must be durable before bounded cleanup, and nested parentage must survive reload and process resume.

Single outcome

bounded workflow.run
  → durable reservation
  → worker terminal, cancel, timeout, invalid output, or failure
  → durable terminal StageResult before bounded cleanup

Implementation

  1. Extract cohesive reservation, worker execution, terminalization, and cleanup components; keep the orchestration function small enough to review.
  2. Race cancellation and deadline against spawn, subscription, and execution. Persist Cancelled or TimedOut when the signal wins, then bound interrupt and cleanup independently.
  3. Enforce a small stage_id byte limit before reservation and in the tool schema so model-visible terminal metadata cannot violate context caps.
  4. Persist the enclosing invocation identity in durable thread/session metadata. Restore it on every worker resume/reload path and populate parent_invocation_id for nested calls.
  5. Reattach actual resumed child sessions to the root trace writer from Phase 2A; never open a competing writer or enter the root-recovery path from child session construction.

Exact surfaces

  • codex-rs/core/src/workflow/invocation.rs — bounded stage lifecycle.
  • codex-rs/core/src/agent/control.rs — durable worker metadata contract.
  • codex-rs/core/src/agent/control/spawn.rs — initial spawn and resume reconstruction.
  • codex-rs/core/src/agent/registry.rs — live worker identity and writer attachment.
  • codex-rs/core/tests/suite/workflow.rs — live terminal and resume proof.

Proof

Table-driven integration coverage replays success, invalid output, cancellation, timeout, worker failure, and persistence failure. A subprocess or lifecycle harness actually stops the original runtime, resumes from disk, preserves the deadline, terminalizes the abandoned attempt, increments the next attempt, and retains nested parentage after worker reload.
