Phase 3 · Restricted agent-authored TypeScript

Complete the defining product path: Codex accepts agent-authored TypeScript, transpiles it on the host, and runs the JavaScript artifact in the existing restricted V8 isolate. TypeScript never gains Node, filesystem, or network authority.

Compilation artifact

WorkflowProgram {
  source_ts, source_sha256,
  compiled_js, compiled_sha256,
  source_map, compiler_name, compiler_version,
  compiler_options, diagnostics, compiled_at
}

Implementation

  1. Add a private codex-typescript-compiler crate backed by the workspace-pinned deno_ast crate with its transpiling feature. It parses only the supplied source string and returns JavaScript, source map, and diagnostics.
  2. Add codex-rs/code-mode-protocol/src/typescript.rs for compiler input, diagnostics, and persisted evidence; codex-code-mode calls the compiler crate through one typescript.rs boundary.
  3. Strip types only; reject decorators, declaration emission, ambient modules, dynamic import, and compiler plugins.
  4. Retain the existing module allowlist. Compilation must not resolve packages or read arbitrary files.
  5. Persist source TypeScript, compiled JavaScript, source map, compiler identity/options, hashes, and diagnostics before evaluation.
  6. Map compile and runtime failures back to TypeScript locations in the terminal StageResult.
  7. Update codex-rs/Cargo.toml, both affected crate manifests and BUILD.bazel files, codex-rs/Cargo.lock, and MODULE.bazel.lock; run just bazel-lock-update with the dependency change.

Proof

Integration tests compile and execute typed orchestration with workflow__run, map a thrown error to the TypeScript source line, reproduce identical JavaScript from persisted compiler evidence, and reject package imports, dynamic imports, Node globals, filesystem, and network access.

Stop: no package manager, arbitrary imports, type-checking service, generic DSL, alternate compiler backends, or suspended-program replay.
